# 無財の七施で、sukhi の見えるところを考えなおす

`KINDNESS.md` は「画面が相手に負っているもの」を九つの約束で書いた。
このページは、同じ場所を別の灯りで照らす。仏典の「無財の七施」──お金も物もいらない、
だれにでもできる七つの施し──を、sukhi の画面と機能に当ててみる。
約束を増やすためではなく、「すでに親切なところ」と「まだ手が届いていないところ」を、
もうひとつの言い方で見つけるための表。`KINDNESS.md`・`KINDNESS_AUDIT.md`・
`KINDNESS_TASKS.md` と重なるところは、そちらの番号(約束 N、T0〜T7)を指す。

**「七」について。** 依頼には「八施」とあったが、正典の教え(雑宝蔵経)は
「無財の七施」で、眼施・和顔悦色施・言辞施・身施・心施・床座施・房舎施。
そう読んで進めた。八つめを別に考えていたなら、教えてほしい。足すだけで済む。

**調べたこと。** `web/src`(SPA)の画面・文面(`ja.ts`)と、`elixir/` の混雑まわり
(待機列、おいた枠)を、コードで読んだ。画面は動かしていない。`ko.ts` と
`web-natadeco` は読んでいない。「確認できていない」と書いたものは、本当に未確認。

## 七つと、sukhi

### 1. 眼施 ── やさしいまなざしを向ける

見てもらえている、と感じられること。数や順位で人を測らないこと。

- **すでに合っている。** 通知で、返信・申請などの「あなたへ」を先に、お気に入りやブーストは
  別の「反応」に分けている(`routes/notifications`)。お知らせ(push)は本文も数字も出さない
  (`push.never`)。配信の進み具合は、相手のサーバ名も数も出さない。
- **足りない。** お気に入り・ブースト・フォロワーの数が常に出る(約束 8、T4)。
  画像に説明文(alt)を書く欄が、書く画面に見当たらない(読む側は `alt` を出している)。
  見えない人・読み上げで読む人は、そこで置いていかれる。
- **案。** 「数を隠す」設定(T4)。画像の説明を書く欄を、「あとからでもいい」と添えて足す。

### 2. 和顔悦色施 ── おだやかな顔で接する

画面の表情。叱らない、急かさない、同じ顔でいる。

- **すでに合っている。** 失敗の文面はやわらかく、書いたものは残ると伝える
  (`compose.err.*`、`busy.banner`)。待機列は、待たされるときも画面に出さず静かに待つ。
- **足りない。**
  - おいた枠の「おいたはダメだよ〜」(`rate_limit_plug.ex`)は、遊び心のつもりでも、
    共有回線で巻き込まれた人には、叱られたように読める(約束 1)。画面でどう出るかは未確認。
    「少し続けて来ていただいたので、しばらくお休みしてください。○分ほどで戻れます」の調子が、
    事実と次の一手がそろう。
  - `check.err.internal_error`「サーバの中で、なにかが転びました」は、次の一手がない(約束 3)。
  - 配信の段の名前は技術の声のまま(`キューに割り当てました`、`フローを完了しました`)。
    だれに向けた顔かを、決めてよい。
- **案。** 429 と 503 のすべての文面を、ひとつの表に並べて、同じ声に揃える(小さな PR)。

### 3. 言辞施 ── やさしいことばをかける

投稿の中身はその人のものなので、画面が代わりに言うことばを見る。

- **すでに合っている。** 「ようこそ」「おかえりなさい」(`invite.welcomePre`、`landing.enterDesc`)。
  空の画面が責めない(`timeline.emptyBubble`「ご近所は、いまは静かです。」)。
  フィードバックは「ちゃんと読みます」と返す。
- **足りない。**
  - 通報は `prompt()` の素のダイアログ(`StatusActions.svelte`)。通報する側は、たいてい傷ついている。
    ここがいちばん機械的な声になっている。
  - 通知の文面は事実だけ(`notif.followed` ほか)。それで十分だが、
    「リアクション」の語彙は、ありがとう・うれしい・わかる、のような受け取りの絵文字が
    先に並ぶと、言いやすい。
  - 初めての投稿のとき、迎えることばが無い。
- **案。** 通報を、画面内の小さなフォームにする(理由、ミュートも同時に、「あとで消せます」)。
  送る前の「ひと呼吸」は、本人が選んだときだけ(既定にしない。約束 9)。

### 4. 身施 ── 体をつかって助ける

人の代わりに手を動かすこと。面倒を引き受けること。

- **すでに合っている。** 下書きを覚え、ログインしていればサーバにも置く。
  フォロー後に相手の過去の投稿を取りに行く(`OutboxBackfill`)。書き出し・引っ越し・
  古い投稿の掃除(`migration`、`cleanup`)。混んだときは、画面に出さず代わりに待って送りなおす。
  時間をきめて出す投稿。
- **足りない。**
  - 投稿の編集が無い(`edited_at` は常に nil。T5)。間違いを直すのに、削除しか道が無い。
  - 削除は取り消せない(T7)。
  - 混んでいるとき、SPA が白紙で長く待つ(TODO「blank SPA」)。待つ人の代わりに、
    骨組みだけでも先に見せるのが、ここでの身施。
- **案。** T5 → T7 の順(`KINDNESS_TASKS.md`)。混雑中の骨組み表示は TODO にある。

### 5. 心施 ── こころを寄せる

相手のしんどさを、案ずること。静める道を、見つけやすいところに置くこと。

- **すでに合っている。** ミュート・ブロックがある。私的メモ(呼び名)は、本人の名前を
  上書きしない。お知らせは呼びかけと申請だけ。タイムラインで、ブーストや
  センシティブ・CW をまとめて隠せる(`timeline.hideSensitive`)。
- **足りない。**
  - 他人の投稿の「…」に、ミュート・ブロックが無く、「通報」だけがある(約束 2、T6)。
    荒れた場面で、静める道より先に「告げる」道が出る形になっている。
  - 会話(スレッド)のミュートが無い(API から要る)。
  - 通知を、時間で静かにする仕組みが無い。
- **案。** T6。続いて「しばらく静かにする」を一つのスイッチにまとめる
  (数を隠す・反応の通知を止める・push を止める、を一度に。期限つきで、自動で戻る)。

### 6. 床座施 ── 席をゆずる

場所をあけて、ほかの人が入れるようにすること。

- **すでに合っている。** これは、画面の外にいちばんよく出ている。
  待機列は人の呼び出しを先に通し、裏の仕事は人の後ろに並べる(`x-sukhi-purpose: background`)。
  軽い匿名の読み取りは、列に入れず通す。「続きを読む」で長い投稿が場所を取りすぎない。
  ご近所タブ(`timeline.tabBubble`)は、近くの流れだけを見られる席。中身の仕組みは読んでいない。
- **足りない。**
  - 同じ回線の人は、ひとりの暴走で一緒に席を失う(おいた枠は IP 単位。
    アカウント別制限が入るまでの宿題。メモ `rate-limit-penalty-box`)。
  - 投稿をたくさんする人が、ホームを埋められる。表示は、時間順だけで、
    ほかの人の席を守る仕組みは無い。
- **案。** ホームで、同じ人の連続した投稿を一まとまりに畳む(「この人の投稿 ほか4つ」)。
  順位づけではなく、畳みだけ。まだ誰にも返事されていない投稿を、数を出さずに
  上に並べる「返事を待っている」の小さな棚も、席をゆずる形のひとつ。

### 7. 房舎施 ── 宿をあたえる

雨風をしのげる場所。来る人にも、行く人にも。

- **すでに合っている。** sukhi そのものが、この施し。招待コードで迎え、
  アカウントがなくても、ご近所の流れをのぞける(`landing.peek`)。路線図で
  中の仕組みを見せる。引っ越し先を決める道と、書き出しがある。
- **足りない。**
  - アカウントを「お休み」にする道、閉じる道が、設定に見当たらない(約束 9)。
    入るのが易しいなら、出るのも同じだけ易しくしたい。
  - 招待してくれた人と、招かれた人のつながりが、入ったあとに見えない。
    初日にいちばん頼れるのは、招いてくれた人。
  - はじめての人の最初のホームは空っぽ(`timeline.emptyHome`)。
- **案。** 「お休み」(ハンドルを守ったまま静かになる)と、閉じる道。
  初日だけ、招待した人の名前と「ここから話しかけられます」を出す。
  空っぽのホームには、ご近所の流れのほうへ誘う一行。

## 決めてもらいたいこと

1. **おいた枠の文面。** 「おいたはダメだよ〜」は sukhi らしい声でもある。
   遊びの声を残すか、事実と次の一手を先に出して、遊びは添えるだけにするか。
2. **「ひと呼吸」。** 送る前の確認を、持つこと自体が押しつけになりうる。
   入れるなら、本人が選んだときだけ。入れないという選択もある。
3. **畳みと棚(床座)。** 順位づけの手前で止める線を、どこに引くか。

## このページに入れなかったこと

- 仏典の解釈そのものは、ここでは決めない。七つは、画面を見るときの七つの問いとして使った。
- 数値や保証(「これで荒れが減る」など)は書いていない。測っていない。
