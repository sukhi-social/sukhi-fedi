# 親切の基準 — what "kind" means on a sukhi screen

`UX_CONTRACT.md` says what a press, a key and a back gesture *do*.
`UI_UX_REVIEW.md` says how it *looks*. This page says what a screen owes
the person looking at it. It is a draft: change anything.

Each promise is written so a reviewer can answer yes or no to it, in the
same way `CODE_STYLE.md` asks of a security or performance property.

## 約束

1. **同じ側に立つ。** 画面は相手を管理も評価もしない。警告と禁止の文面は、責める調子にしない。
   事実を言い、「悪い」と断じない。(mettā — 友であること)
2. **静める道を、同じ大きさで置く。** ミュート、通知の一時停止、距離をとる操作、
   見たくないものの折りたたみは、ブロックや通報と同じくらい見つけやすい。
   荒れた場面を「倒す」ことだけを、目立たせない。見ても、そこに住まなくていい。
   (√śam — 静まること)
3. **よく見て、はっきり言う。** 失敗したら、何が起きたか・なぜか・次の一手、を書く。
   進行中のものは、進行中だと見せる。「エラーが発生しました」で終わらない。
   (√lok — 見ること / 明確であること)
4. **安心させる。** エラーや警告は、不安を増やさない書き方にする。
   「よくあることです。大丈夫、こうすれば直ります」の調子。
5. **覚えておく。** 下書き、入力の途中、開いていた位置は、戻ってきた人のために残す。
   同じことを二度させない。(sati — 忘れずにいること)
6. **完璧を求めない。** 編集、取り消し、下書きへの戻しを、いつでもできるようにする。
   間違いを、恥にしない。言葉づかいは軽く。
7. **相手の注意に見合う。** 通知、バナー、メールの催促(`EmailNudge`、`UpdateBanner`、
   `AnnouncementsBanner` など)は、取る注意より大きな役に立つときだけ出す。
   (使う価値は、払ってもらう価値より大きく)
8. **競わせない。** 数(フォロワー、ブースト)や、引用で相手を晒す見せ方で、
   優越を競わせない。同意を求め合う構図を、既定にしない。
9. **押し切らない、依存させない。** だましの導線も、外しにくい同意も、習慣化だけを狙う仕掛けも
   置かない。書き出し・退会・やめるが、入るのと同じくらい易しい。

## 聞くこと(フィードバック)

- **どの画面からも、すぐ届けられる。** 隅に小さな口を置く。画面名・言語・バージョンだけを
  自動で添え、それ以外は相手が書いたものだけにする。
- **受け取ったら、すぐ返す。** 「届きました、ありがとう」。どう扱われたかも、あとで返す。
- **口は広く、聞き分けはあとで。** 全部を受け取る。そのうえで、実際にためになる意見は
  取り入れ、ただ反対するだけの声には引きずられない。聞き分けは受け取ったあとの仕事で、
  口を狭めることではない。
- **先に確かめ、それから感じる。** 受け取った意見に気持ちが動いても、まず「何が起きているか」
  「役に立つか」を確かめ、そのあとで気持ちを合わせる。逆の順にしない。

## 点検のやり方

timeline、compose、通知、設定、signup を、上の約束ごとに見て、表にする。
足りないところは、小さな PR で順に直す。`UI_UX_REVIEW.md` の「次にやること」も合流させる。

## 出どころと、使わないこと

約束 1〜5 の一部は natadeco の注釈(慈経、世尊偈)から、7 と 9 は Wattles『The Science of
Getting Rich』(1910) の「使う価値」と「意志は自分にだけ」から、2・4・6・8・9 は
Hawkins『In the World, But Not of It』(2023) の読みから取った。基準そのものは、これらの
思想を信じなくても、画面を見れば確かめられる形にしている。

使わないもの:

- 意識レベルの数値、筋反射テスト、カルマの説明など、検証されていない主張。
- 「必ず成功する」といった保証、苦しみの話を遠ざける考え方、懐疑を下に見る考え方。
- 政治・性別・国についての記述。
