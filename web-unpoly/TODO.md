いまの `/`(server/routes/auth.ts の `route('GET', '/')`)は、はじめての人にも入口を見せ、
入っている人は `/timeline` へ送っている。これを、次のように変える予定。

| だれが             | どこへ                                                                                                                            |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| はじめての人       | `about.sukhi.social` へ。そこにログインボタンを置く予定で、`/login?welcome=true` につなぐ。**加入(signup)への道も、目立たせる。** |
| ログインしている人 | `sukhi.social` へ。`/timeline` は付けない                                                                                         |
| ログインが切れた人 | `/login?again=true` へ                                                                                                            |

`/login` の見せ方:

| URL                                                 | 加入への道 |
| --------------------------------------------------- | ---------- |
| `/login?welcome=true`(about から来た、はじめての人) | 目立たせる |
| `/login`(ふつう)                                    | そっと置く |
| `/login?again=true`(切れた人)                       | そっと置く |

### あしたに置いている問い(決まっていないので、決めたふりをしない)
