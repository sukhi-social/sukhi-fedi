### Mastodon and Misskey

- [Mastodon](https://joinmastodon.org/): the Mastodon client API is the main surface sukhi speaks to apps.
- [Misskey](https://misskey-hub.net/): sukhi federates with it, and carries its custom-emoji reactions and quote posts.

[The FEP process](https://fediverse.codeberg.page/fep/) and its authors. The proposals sukhi uses:

- [FEP-044f](https://fediverse.codeberg.page/fep/fep/044f/): Consent-respecting quote posts
- [FEP-8b32](https://fediverse.codeberg.page/fep/fep/8b32/): Object Integrity Proofs
- [FEP-e232](https://fediverse.codeberg.page/fep/fep/e232/): Object Links
- [FEP-8fcf](https://fediverse.codeberg.page/fep/fep/8fcf/): Followers collection synchronization across servers
- [FEP-1b12](https://fediverse.codeberg.page/fep/fep/1b12/): Group federation
- [FEP-bebd](https://fediverse.codeberg.page/fep/fep/bebd/): Follow Invites
- [FEP-521a](https://fediverse.codeberg.page/fep/fep/521a/): Representing actor's public keys
- [FEP-8967](https://fediverse.codeberg.page/fep/fep/8967/): Generating link previews for attached links
- [FEP-7458](https://fediverse.codeberg.page/fep/fep/7458/): Using the replies collection
- [FEP-5feb](https://fediverse.codeberg.page/fep/fep/5feb/): Search indexing consent for actors
- [FEP-4ccd](https://fediverse.codeberg.page/fep/fep/4ccd/): Pending Followers Collection and Pending Following Collection
- [FEP-7888](https://fediverse.codeberg.page/fep/fep/7888/): Demystifying the context property
- [FEP-67ff](https://fediverse.codeberg.page/fep/fep/67ff/): FEDERATION.md

<h2 id="standards">Standards</h2>

### Languages

- [ECMAScript](https://tc39.es/ecma262/), Ecma International, TC39

### Federation

- [ActivityPub](https://www.w3.org/TR/activitypub/), W3C
- [JSON-LD 1.1](https://www.w3.org/TR/json-ld11/), W3C
- [RDF Dataset Canonicalization (RDFC-1.0)](https://www.w3.org/TR/rdf-canon/), W3C
- [WebFinger (RFC 7033)](https://www.rfc-editor.org/rfc/rfc7033), IETF
- [host-meta (RFC 6415)](https://www.rfc-editor.org/rfc/rfc6415), IETF
- [NodeInfo](https://nodeinfo.diaspora.software/), the NodeInfo authors

- [JSON Canonicalization Scheme (RFC 8785)](https://www.rfc-editor.org/rfc/rfc8785), IETF

- [Web Push (RFC 8030, RFC 8291, RFC 8292, RFC 8188)](https://www.rfc-editor.org/rfc/rfc8030), IETF
- [JSON Web Key (RFC 7517)](https://www.rfc-editor.org/rfc/rfc7517), IETF
